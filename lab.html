01 / markdown files

What's a markdown file? (A .md file)

It's just a text file — like a note on your phone — with a few simple symbols that make it neat. That's it. No special program needed.

📝 It's plain text

Opens on any phone or computer, forever. It never breaks, never needs an app, never costs money.

# Symbols = structure

A # makes a title. A - makes a bullet. **two stars** make bold. You already know enough.

🤖 AI speaks it natively

AI reads and writes markdown better than anything else. Hand an AI a .md file and it knows exactly what you mean.

📦 It's portable

Write it once, paste it into ChatGPT, Claude, Gemini — any AI, any time. Your plan goes wherever you go.

Why we use it:

When you ask AI to “create a markdown file,” you get a clean, organized document you can save, edit, and hand to the next AI. It's the difference between a pile of sticky notes and a folder with labels.

02 / files & folders

Why we put files in folders.

A file is one piece of paper. A folder is a labeled envelope that holds papers. Folders can go inside folders. That's the whole idea — and it's how you find anything in 10 seconds instead of 10 minutes.

📄 File

One thing: your resume, a letter, a plan. Ends in a type, like .md, .pdf or .jpg.

📁 Folder

A container with a name. Jobs, ID & Papers, Goals. Put related files together.

🧭 Path

The address of a file: My Life / Jobs / resume.md. Like a street address, but for your stuff.

🤖 Why AI cares

One project = one folder. Builder AIs (like Claude Code) read a whole folder at once and understand your whole project.

    03 / the handoff · prompt #1

    Talk messy. Get a plan. Get it built.

    You don't need to know how to build anything. You need to know how to describe it. Here's the trick: one AI turns your messy thoughts into a clean markdown plan. A fresh AI reads that plan and builds it in one shot.

    the prompt 
    Create a markdown file about what I'm about to say, so the next bot will build it for me in one shot.
    1 You talk (messy is fine)
    2 AI #1 writes plan.md
    
        
    3 AI #2 builds it
    
      
    
      
    
        
        
        
      
    
      
    Why a fresh chat?
    Long chats get cluttered and the AI starts forgetting the early stuff. A clean plan file in a brand-new chat = the AI sees exactly what matters, nothing else.
